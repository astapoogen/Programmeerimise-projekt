# Programmeerimise-projekt

* Meie projektiks on The Binding of Isaac mängu abiprogramm, mis aitab leida esemete sünergiaid ja valida sobivaid esemeid. See on mõeldud eelkõige uutematele mängijatele, kellel on raske mängu paljude esemete ja nende mõjudega kursis olla. Valisime selle teema, sest mängime mõlemad seda mängu ning tahaksime teha midagi kasulikku teistele mängijatele ja samal ajal oma programmeerimisoskusi arendades.
